# Project

- Name: Agent Usage Hub
- Goal: Collect ccusage-supported Agent usage and arbitrary application usage from distributed collectors, aggregate on a server, and explore through a web dashboard.
- Runtime: Node.js 24+, built-in SQLite, dependency-free native collectors for the 18 ccusage 20.0.26 sources, static HTML/CSS/JS UI.
- Package: one npm package and one `agent-usage` binary with `install server` / `install collector` role selection.
- Operation: public GitHub source repository; runtime package remains a local tarball, with no npm publication or remote server deployment yet.
